# Boolean Field Template

A generic toggle custom field using `Toggle` from the Strapi Design System.

- **Field type:** `boolean`
- **Use case:** Flags, toggles, on/off values, feature switches

Placeholders: `{{FIELD_NAME}}`, `{{PLUGIN_ID}}`, `{{DISPLAY_NAME}}`, `{{DESCRIPTION}}`, `{{ICON_NAME}}`, `{{COMPONENT_NAME}}`
